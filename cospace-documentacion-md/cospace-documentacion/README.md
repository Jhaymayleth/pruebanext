# CoSpace

Plataforma fullstack para explorar y reservar espacios de coworking: escritorios, salas de reuniones y cabinas.

## Estado del proyecto
- Fase actual: planificación documental.
- Tiempo máximo de la prueba: 7 horas de reloj, de 06:00 a 13:00.
- Importante: el horario incluye tres descansos; el tiempo efectivo de desarrollo es de aproximadamente 6 horas.
- Las decisiones tecnológicas marcadas como **propuestas** deben confirmarse antes de implementar.

## Requisitos de entrega extraídos del instructivo
El README definitivo debe explicar los requisitos previos, cada variable de entorno, los comandos exactos de instalación y ejecución, migraciones, seed, credenciales del administrador de prueba, Docker, scripts del `package.json`, estructura de carpetas y URL desplegada.

La entrega también contempla un repositorio público de GitHub, un TXT con el enlace y un ZIP del proyecto. No incluir secretos reales en el repositorio ni en `.env.example`.
